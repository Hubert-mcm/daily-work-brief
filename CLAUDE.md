# Daily Work Brief — standing instructions

Each daily "Hubert Work Briefing" must:
- Be saved as `briefings/YYYY-MM-DD-hubert-work-briefing.md` and copied into `latest-brief.md`.
- Include a **"People to Follow Up Today"** section (table: Who / Topic / What to chase) built from recent Outlook emails and calendar: unanswered outbound requests, quotes/reports awaited, open tickets, and deadlines. Include named suppliers (e.g. Billy, Mina, Abdel, Coates) and colleagues.
- Be pushed to the default branch `claude/quirky-goldberg-si1fmj` (authorised by the user) as well as the session branch.
